# Perfil del equipo

**Formación:** Tecnicatura en Programación
**Proyecto:** Solis Umbra (roguelike de decisiones, Game Jam Java), desarrollado en equipo

## Habilidades
- Programación orientada a objetos en Java: clases, herencia, interfaces, polimorfismo y encapsulamiento.
- Estructuras de datos propias: listas enlazadas, pilas, colas y grafos con listas de adyacencia.
- Persistencia en archivos de texto con `java.io` (`BufferedReader`, `PrintWriter`) y manejo de excepciones.
- Arte y diseño de interfaz: fondos, paneles, sprites con poses, fuentes, puntero e ícono propios.
- Control de versiones con Git y GitHub.
- Experiencia en desarrollo web (HTML, CSS, JavaScript), que ayuda a pensar pantallas e interfaces.

## Fortalezas
- **Resolutivo:** cuando algo falla, se aísla, se reproduce y se busca la causa antes de tocar código.
- **Lógico y analítico:** los problemas grandes se dividen en piezas chicas que se pueden probar por separado.
- **Responsable:** se cumplen los plazos y se deja documentado lo que se hace.
- **Autocrítico:** el código propio se revisa como si lo hubiera escrito otra persona.
